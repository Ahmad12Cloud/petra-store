English

Insulated twin cord end ferrule that joins two flexible wires of the same size in one tube, so both can be clamped together in a single terminal without frayed strands. It gives a firm, safe connection in breakers, contactors and terminal blocks inside distribution panels.

Technical specifications

  • Type: Twin insulated cord end ferrule – two wires
  • Series: TE
  • Available sizes (Cross section): 2×0.5 / 2×0.75 / 2×1 / 2×1.5 / 2×2.5 / 2×4 / 2×6 / 2×10 / 2×16 mm²
  • Tube material: Tinned copper
  • Insulation collar: PP plastic
  • Color code: a different color for each size
  • Installation: Ferrule crimping tool

Applications: connecting two wires to the same terminal in distribution and control panels, breakers, contactors, relays and solar PV systems.
