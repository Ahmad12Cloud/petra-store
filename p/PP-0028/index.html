English

GEYA W2R-100 II Automatic Transfer Switch (ATS): automatically transfers the load between two power sources (mains and generator). When the main source fails it switches to the backup source, and switches back when the main source returns. Works in automatic (Auto) or manual (Manual) mode with the transfer handle.

Available in two versions (choose the number of poles when ordering):

  • 2P – 230V AC (phase + neutral).
  • 4P – 400V AC (3 phases + neutral).

Technical specifications

  • Brand: GEYA
  • Model: W2R-100 II
  • Rated current (Ie): 100A
  • Poles: 2P / 4P
  • Rated operational voltage (Ue): 230V AC (2P) – 400V AC (4P)
  • Rated insulation voltage (Ui): 690V AC
  • Rated impulse withstand voltage (Uimp): 8kV
  • Control voltage (Us): 230V AC – 50/60Hz
  • Class: PC – transfer only, no overload or short-circuit protection; install a suitable protective breaker upstream
  • Transfer type: break-before-make, the two sources are never connected together
  • Operation: Automatic / Manual
  • Status signal contacts: NO / C / NC per source
  • Mounting: 35mm DIN rail
  • Standard: IEC 60947-6-1 / GB/T 14048.11
