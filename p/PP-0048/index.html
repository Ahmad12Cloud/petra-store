تايمر رقمي (Digital Time Relay) من شركة Aoasis، موديل ADRV-10، بشاشة رقمية تعرض الوقت. يشتغل بطريقتين (مرحلتين) حسب اختيارك:

1) تأخير التشغيل (ON Delay): بعد وصول إشارة البدء (Trigger) على الطرف TR، ينتظر التايمر الوقت المضبوط ثم يشغّل الريليه (الخرج). مثال: تأخير تشغيل مكيف أو موتور أو كمبروسر بعد رجوع الكهرباء.

2) تأخير الفصل (OFF Delay): يشتغل الخرج فوراً مع وصول إشارة البدء، وبعد انقطاع الإشارة يبقى شغّال لمدة الوقت المضبوط ثم يفصل. مثال: مروحة شفط أو إنارة درج تبقى شغّالة مدة بعد الإطفاء.

طريقة الضبط

  • مفتاح x (تحت): يختار نوع التشغيل والمدى معاً – ON DLY (أسود): 9.9s / 99s / 9.9m / 99m – OFF DLY (أخضر): 9.9s / 99s / 9.9m / 99m
  • مفتاح t (فوق): يضبط الوقت من 0 لآخر المدى المختار

  • مؤشرات: TRG (وصول إشارة البدء) – RLY (حالة الريليه)

English

Aoasis ADRV-10 digital time relay with a digital time display. It works in two modes of your choice:

1) ON Delay: after the start (trigger) signal arrives on the TR terminal, the timer waits for the set time and then switches the relay output on. Example: delaying an air conditioner, motor or compressor start after power returns.

2) OFF Delay: the output switches on immediately with the trigger signal; when the signal is removed it stays on for the set time and then switches off. Example: an extractor fan or staircase light staying on for a while after switching off.

Setting

  • x knob (lower): selects the mode and range together – ON DLY (black): 9.9s / 99s / 9.9m / 99m – OFF DLY (green): 9.9s / 99s / 9.9m / 99m
  • t knob (upper): sets the time from 0 up to the end of the selected range
  • After changing the range with the x knob, switch the power off and on for the new range to apply
  • When counting in minutes, the decimal point on the display flashes
  • Indicators: TRG (trigger signal present) – RLY (relay state)

  • Operating temperature: -20°C to +55°C

  • A1 – A2: 230V AC supply
  • A2 – A3: 24V AC/DC supply
  • TR: start (trigger) input
  • 1 – 2 – 3: relay output (2 common)

Applications: delaying the start of air conditioners, compressors and motors after power returns, delaying the switch-off of fans and lighting, and control and automation panels.
